## Conventions

Ces documents décrivent ce que le code fait aujourd'hui, pas ce qui est prévu.
Une fonctionnalité non vérifiée n'y figure pas, ou est signalée comme telle.

Les chiffres cités viennent du code. S'ils divergent, c'est le code qui a
raison et la page qui est en retard : signalez-le.
